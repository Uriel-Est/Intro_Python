Introdução aos Softwares Estatísticos

Objetivo. Apresentar, de forma prática, os fundamentos de Quarto, Git/GitHub, pip e conceitos básicos de Python para que você consiga preparar, versionar e publicar materiais de aula e relatórios reproduzíveis.

Nota

Dica rápida: use quarto preview para ver a página atualizando a cada gravação e quarto render para produzir a versão final.

1 Quarto

Quarto é um sistema de publicação científica que permite produzir páginas web, relatórios e slides a partir de arquivos Markdown (com blocos de código opcionais).

  • Arquivos .qmd misturam texto, figuras e código (R, Python, etc.).
  • Você pode publicar como site ou como documento único em HTML/PDF.
  • Renderização local: quarto preview (hot-reload) e quarto render (build final).

1.1 Estrutura mínima de um .qmd

---
title: "Meu documento"
format:
  html:
    toc: true
---

# Seção
Texto **Markdown** normal.

::: {#bced443d .cell execution_count=1}
``` {.python .cell-code}
print("Olá, Quarto!")
```

::: {.cell-output .cell-output-stdout}
```
Olá, Quarto!
```
:::
:::

1.2 Organização recomendada

  • Títulos hierárquicos (#, ##, ###) com IDs estáveis usando {#meu-id}.
  • Tabela de conteúdo (toc: true) para navegação lateral.
  • Use callouts para dicas, avisos e observações.

2 Git e GitHub

Git é um sistema de controle de versões que permite rastrear mudanças e colaborar. O GitHub é um serviço que hospeda seus repositórios online.

2.1 O que são

  • Git: ferramenta local de versionamento.
  • GitHub: plataforma remota para backup, colaboração e publicação (inclui GitHub Pages).

2.2 Para que servem

  • Histórico e rollback de alterações.
  • Trabalho em equipe via branch/pull request.
  • Publicação de sites (ex.: páginas Quarto em docs/).

2.3 Comandos básicos

git init                  # inicia repositório
git add .                 # adiciona mudanças
git commit -m "primeiro commit"
git remote add origin https://github.com/usuario/repositorio.git
git push -u origin main   # envia branch principal
git pull                  # puxa mudanças
git clone <url>           # clona repositório existente
Dica

Fluxo enxuto: edite → git add -A → git commit -m "msg" → git push.

3 pip

3.1 O que é

pip é o gerenciador de pacotes do Python.

3.2 Como instalar pacotes

# Instalar
pip install pandas numpy matplotlib requests

# Atualizar pacote
pip install --upgrade pandas

# Congelar dependências
pip freeze > requirements.txt

# Instalar a partir do requirements
pip install -r requirements.txt

3.3 Bibliotecas populares

  • pandas — dados tabulares
  • numpy — vetores, matrizes e numérico
  • matplotlib — gráficos
  • requests — HTTP simples

4.4 Estruturas de controle

# if / elif / else
nota = 8.3
if nota >= 7:
    status = "aprovado"
elif nota >= 5:
    status = "recuperação"
else:
    status = "reprovado"

# for
quadrados = [i*i for i in range(5)]

# while
i, soma = 0, 0
while i < 5:
    soma += i
    i += 1

status, quadrados, soma

4.7 Boas práticas

  • Comentários curtos e úteis.
  • Nomes descritivos (snake_case).
  • Indentação consistente (4 espaços).
  • Fixe dependências em requirements.txt.
  • Use notebooks e .qmd reproduzíveis.
